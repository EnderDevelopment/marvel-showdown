# Roblox Marvel Game

This project is a Roblox game featuring multiple Marvel characters with unique abilities, a start menu, and settings. The game includes scripts for character abilities, a start menu, and settings, allowing players to test different Marvel characters and their abilities in a customizable environment.

## Install

1. Open Roblox Studio.
2. Create a new place or open an existing one.
3. Navigate to the `ServerScriptService` in the Explorer.
4. Create a new `Script` and name it `StartMenuScript`.
5. Paste the content of `StartMenuScript.server.lua` into the script.
6. Repeat steps 4 and 5 for `SettingsScript` and `CharacterAbilitiesScript` with their respective content.

## Use

1. Launch the Roblox game.
2. Use the start menu to begin the game.
3. Navigate to the settings menu to customize your experience.
4. Select a Marvel character and test their unique abilities.
